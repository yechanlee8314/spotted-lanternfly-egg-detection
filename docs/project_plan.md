# Spotted Lanternfly Detection

## Goal

Develop a computer vision system capable of identifying spotted lanternflies and their egg masses from photographs.

## Motivation

The spotted lanternfly is an invasive insect causing significant ecological and agricultural damage in the northeastern United States.

## Current Progress

- Literature review
- Dataset collection
- Image annotation
- Baseline YOLO model
- Model evaluation

## Future Work

- Egg mass detection
- Mobile deployment
- Real-time inference
